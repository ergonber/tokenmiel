# docs/business/

Documentos de negocio, propuestas, y artefactos legales/comerciales del proyecto tokenization-platform.

## Contenido

- `PROPUESTA-TOKENIZACION-MIEL-BOLIVIANA.md` — propuesta conceptual y legal del primer caso de uso (miel monofloral boliviana).

## Diferencia con `docs/architecture/`

- **`docs/architecture/`** — decisiones técnicas (ADRs, contract specs, test specs, flows operacionales).
- **`docs/business/`** — propuestas, modelos financieros, memoranda legales, pitch decks, estudios de mercado.

## Responsabilidad

La propuesta legal/comercial es responsabilidad del compañero legal del proyecto. El scope técnico de este repo NO es modificar estos documentos sin coordinación legal.
